# 🥚 HuevoApp - Temporizador de Cocción de Huevos

**HuevoApp** es una aplicación de escritorio desarrollada en **Java Swing** como ejercicio práctico para mejorar mis habilidades en Java y experimentar con nuevas funcionalidades.

La aplicación permite al usuario elegir un tipo de huevo según su punto de cocción preferido (pasado por agua, medio o duro), y activa un temporizador con la duración adecuada. Al finalizar el tiempo, suena una alarma para avisar que el huevo está listo. El usuario puede iniciar o detener el temporizador manualmente en cualquier momento.

---

## 🚀 Características

- Interfaz gráfica creada con Java Swing.
- Selección de tipo de cocción (distintos tiempos por huevo).
- Temporizador visual con cuenta regresiva.
- Sonido de alarma al finalizar el tiempo.
- Control manual para iniciar y detener el temporizador.
- Incluye imágenes y un vídeo demostrativo del funcionamiento.
